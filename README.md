# Portfólio – Gustavo Barreto

Trabalho de HTML/CSS do 3º bimestre, feito na disciplina de Informática da E.E.E.P Jeová Costa Lima, em Russas.

## Páginas

- `index.html`: Início (apresentação, tecnologias, ferramentas e links)
- `sobre.html`: Sobre Mim
- `contato.html`: E-mail, GitHub, Instagram, TikTok e WhatsApp

## Estrutura de pastas

```
portfolio-gustavo-barreto/
├── index.html
├── sobre.html
├── contato.html
├── README.md
├── css/
│   └── style.css          (efeitos de mouse e ajustes próprios)
└── img/
    ├── minha_foto_arrumado.jpeg
    ├── foto_com_amigos.jpeg
    ├── python.png  html.png  css.png  portugol.png  php.png  tailwind.png (tecnologias)
    ├── vscode.png  git.png  github.png                           (ferramentas)
    └── email.png  instagram.png  tiktok.png   whatsapp.png       (contato)
```

## Tecnologias usadas

HTML, CSS e Tailwind CSS (carregado pela internet, via CDN).

## Como abrir

Dê dois cliques no `index.html`. É preciso estar com internet para o Tailwind carregar.
